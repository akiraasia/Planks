# 🧬 2. CORE SYSTEM ARCHITECTURE

## 🔷 Layer 1: Model Gateway

Handles:

* API keys
* Model metadata
* Rate limits

```ts
type ModelConfig = {
  id: string;
  provider: string;
  apiKey: string;
  endpoint?: string;
};
```

---

## 🔷 Layer 2: Agent Engine (CORE)

Transforms models → agents

```ts
type Agent = {
  id: string;
  role: string;
  model: ModelConfig;
  state: "idle" | "working" | "error";

  tools: ToolSet;
  memory: MemoryStore;
};
```

---

## 🔷 Layer 3: Role System

Predefined + custom roles:

```ts
type Role =
  | "planner"
  | "frontend"
  | "backend"
  | "reviewer"
  | "orchestrator"
  | "custom";
```

Each role maps to:

* prompt template
* allowed tools
* priority

---

## 🔷 Layer 4: Tooling System

Agents operate ONLY via tools:

```ts
type ToolSet = {
  readFile(path: string): string;
  writeFile(path: string, content: string): void;
  runCommand(cmd: string): string;
  searchCode(query: string): string[];
  callAPI(endpoint: string): any;
};
```

---

## 🔷 Layer 5: Shared Memory + Event Bus

### Memory

* Vector DB (context)
* Project state

### Event Bus (Redis / Kafka)

```json
{
  "type": "TASK_CREATED",
  "source": "planner",
  "target": "frontend",
  "payload": {}
}
```

---

# 🔄 3. FULL PIPELINE FLOW

```
User creates project
        ↓
Adds AI models
        ↓
Assigns roles
        ↓
Chooses orchestration mode
        ↓
Gives task (e.g. "build app")
        ↓

        ↓
Agents execute in parallel
        ↓
Event bus syncs actions
        ↓

        ↓
Code merged
        ↓
Executed in terminal
        ↓
Feedback stored in memory
```
