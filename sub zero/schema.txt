Here’s a **production-grade database schema** for your MADE sub-application—designed to support:

* multi-agent roles
* pluggable AI models
* task graphs (DAG)
* shared code workspace
* terminal execution
* consensus + audit (your strength)

I’ll structure this in **PostgreSQL (relational core) + optional vector store**.

---

# 🧠 0. DESIGN PRINCIPLES

* Separate **Model ↔ Agent ↔ Role**
* Treat **tasks as graph (not list)**
* Log EVERYTHING (for consensus + replay)
* Keep execution isolated per project
* Support future quantum-style extensions

---

# 🧱 1. CORE TABLES

## 👤 users

```sql
CREATE TABLE users (
  id UUID PRIMARY KEY,
  email TEXT UNIQUE NOT NULL,
  name TEXT,
  created_at TIMESTAMP DEFAULT now()
);
```

---

## 📁 projects

```sql
CREATE TABLE projects (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  name TEXT NOT NULL,
  description TEXT,
  orchestration_mode TEXT CHECK (
    orchestration_mode IN ('rule', 'manager', 'consensus')
  ),
  created_at TIMESTAMP DEFAULT now()
);
```

---

# 🔐 2. MODEL & API LAYER

## 🤖 models (user-provided AI configs)

```sql
CREATE TABLE models (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  provider TEXT,              -- openai, anthropic, gemini, local
  model_name TEXT,
  api_key_encrypted TEXT,
  endpoint TEXT,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT now()
);
```

---

# 🧬 3. AGENT SYSTEM

## 🧠 agents

```sql
CREATE TABLE agents (
  id UUID PRIMARY KEY,
  project_id UUID REFERENCES projects(id),
  model_id UUID REFERENCES models(id),
  name TEXT,
  role TEXT,
  state TEXT CHECK (state IN ('idle', 'working', 'error')),
  is_manager BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT now()
);
```

---

## 🎭 roles (optional extensibility)

```sql
CREATE TABLE roles (
  id UUID PRIMARY KEY,
  name TEXT UNIQUE,
  description TEXT,
  default_prompt TEXT,
  allowed_tools JSONB,
  priority INT
);
```

---

# 🧰 4. TOOLING SYSTEM

## 🛠 tools

```sql
CREATE TABLE tools (
  id UUID PRIMARY KEY,
  name TEXT,
  description TEXT
);
```

---

## 🔗 agent_tools (many-to-many)

```sql
CREATE TABLE agent_tools (
  agent_id UUID REFERENCES agents(id),
  tool_id UUID REFERENCES tools(id),
  PRIMARY KEY (agent_id, tool_id)
);
```

---

# 🧠 5. MEMORY SYSTEM

## 📚 memories (structured + embeddings reference)

```sql
CREATE TABLE memories (
  id UUID PRIMARY KEY,
  project_id UUID REFERENCES projects(id),
  agent_id UUID REFERENCES agents(id),
  type TEXT, -- "global", "agent", "task"
  content TEXT,
  embedding_id TEXT, -- link to vector DB
  created_at TIMESTAMP DEFAULT now()
);
```

---

# 🔄 6. TASK GRAPH SYSTEM (CRITICAL)

## 🧩 tasks (nodes)

```sql
CREATE TABLE tasks (
  id UUID PRIMARY KEY,
  project_id UUID REFERENCES projects(id),
  title TEXT,
  description TEXT,
  status TEXT CHECK (
    status IN ('pending', 'in_progress', 'completed', 'failed')
  ),
  assigned_agent UUID REFERENCES agents(id),
  created_by TEXT, -- user or agent id
  created_at TIMESTAMP DEFAULT now()
);
```

---

## 🔗 task_edges (DAG relationships)

```sql
CREATE TABLE task_edges (
  id UUID PRIMARY KEY,
  from_task UUID REFERENCES tasks(id),
  to_task UUID REFERENCES tasks(id)
);
```

👉 This enables:

* parallel execution
* dependency resolution
* graph traversal

# 💻 7. FILE SYSTEM (CODEBASE)

## 📄 files

```sql
CREATE TABLE files (

```

```sql
CREATE TABLE file_versions (

  content TEXT,
  modified_by UUID,
  created_at TIMESTAMP DEFAULT now()
);
```

# ⚖️ 10. CONSENSUS SYSTEM (YOUR CORE)

## 🧠 proposals

```sql
CREATE TABLE proposals (

  created_at TIMESTAMP DEFAULT now()
);
```

## 🗳 votes

```sql
CREATE TABLE votes (

);
```

---

## 🧾 consensus_results

```sql
CREATE TABLE consensus_results (
```
